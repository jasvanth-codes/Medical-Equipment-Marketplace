# Medical Equipment Marketplace

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Features

- User Registration
- User Login
- JWT Authentication
- Product Management (CRUD)
- Product Search
- Category Filter
- Price Sorting
- Shopping Cart
- Wishlist
- Orders
- Reviews
- Responsive UI
- Protected Routes
- Profile Page
- Admin Panel Ready

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
